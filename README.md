## Hi, I'm Matthew Uhlar

Software developer in Austin, TX (open to remote). I build full stack apps with **C# and ASP.NET Core**, **Java and Spring Boot** and **React with TypeScript** on PostgreSQL, containerized with Docker. BS in Computer Science, MS in AI and Machine Learning in progress, Certified SAFe Scrum Master.

I also run IT, finance and operations for a growing multi-site organization, so I build with the end user and the budget in mind.

**Every project below has a recorded demo.** Watch them all on my [portfolio site](https://matthew-uhlar.github.io/Portfolio/).
